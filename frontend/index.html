REST API Reference

Production-ready endpoints adhering to standard HTTP methods and status codes.

POST /api/auth/register
Register a new user account
POST /api/auth/login
Authenticate and receive JWT token
GET /api/tasks
Fetch user tasks with search, filter, and sort (Protected)
POST /api/tasks
Create a new task with due date, priority, and subtasks (Protected)
PUT /api/tasks/:id
Update task details & subtasks (Protected)
PATCH /api/tasks/:id/complete
Toggle task status between Pending & Completed (Protected)
DELETE /api/tasks/:id
Permanently delete a user task (Protected)
GET /api/tasks/stats/summary
Retrieve dashboard summary statistics and category counts (Protected)
