REST API Architecture

This application implements standard RESTful design with JSON payloads and Bearer token JWT authentication in the Authorization header:

Authorization: Bearer <jwt_token>
METHOD ENDPOINT ACCESS DESCRIPTION
POST /api/auth/register Public Register user & get JWT
POST /api/auth/login Public Authenticate & get JWT
GET /api/tasks Private Get user tasks (with search/filter/sort)
POST /api/tasks Private Create new task
PUT /api/tasks/:id Private Update task details
PATCH /api/tasks/:id/complete Private Toggle Pending <-> Completed
DELETE /api/tasks/:id Private Delete task
GET /api/tasks/stats/summary Private Dashboard summary statistics
